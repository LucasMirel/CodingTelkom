Lesson 1: Selectors and Colors

A selector chooses which HTML elements to style.

The color property changes text color, and background-color changes the background.

Use .name for a class and #name for an id.

p {
  color: blue;
  background-color: yellow;
}
.title {
  font-size: 24px;
}
