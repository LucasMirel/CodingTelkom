Lesson 3: Lists

HTML has two main kinds of lists:

  • <ul> makes an unordered list (bullet points).
  • <ol> makes an ordered list (numbered).

Every item inside a list goes in an <li> tag. Example:

<ul>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ul>
